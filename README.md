# Privacy

This repository contains the privacy policy and privacy-related documentation for DTech-Africa projects and services.

## Overview

DTech-Africa is committed to protecting the privacy and security of our users' personal information. This repository provides comprehensive privacy documentation that outlines how we collect, use, and protect user data across all our services.

## Documentation

- **[Privacy Policy](PRIVACY.md)** - Our complete privacy policy document that describes how we handle user information
- **[Data Deletion Request](DATA-DELETION.md)** - Instructions for requesting deletion of your personal data

## Purpose

This privacy policy serves as the standard privacy documentation for:

- DTech-Africa software applications
- Open source projects
- Web services and platforms
- Mobile applications
- Any other services provided by DTech-Africa

## Key Principles

Our privacy approach is built on the following principles:

1. **Transparency** - We are clear about what data we collect and how we use it
2. **User Control** - Users have rights to access, correct, and delete their data
3. **Security** - We implement strong security measures to protect user information
4. **Compliance** - We comply with applicable data protection regulations (GDPR, etc.)
5. **Minimal Collection** - We only collect data necessary for our services
